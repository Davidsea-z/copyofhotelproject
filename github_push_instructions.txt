# GitHub 新分支推送指南

## 方式一：使用现有远程仓库

### 1. 查看当前远程仓库
git remote -v

### 2. 创建新分支 feature/v2.2-investment-tools
git checkout -b feature/v2.2-investment-tools

### 3. 推送到GitHub（需要你的GitHub token）
# 如果使用HTTPS:
git push origin feature/v2.2-investment-tools

# 如果需要设置上游分支:
git push -u origin feature/v2.2-investment-tools

---

## 方式二：推送到你自己的新仓库

### 1. 在GitHub上创建新仓库（例如：hotel-project-v2）

### 2. 添加新的远程仓库
git remote add myrepo https://github.com/你的用户名/hotel-project-v2.git

### 3. 创建新分支
git checkout -b feature/v2.2-investment-tools

### 4. 推送到新仓库
git push -u myrepo feature/v2.2-investment-tools

# 或者推送main分支
git checkout main
git push -u myrepo main
